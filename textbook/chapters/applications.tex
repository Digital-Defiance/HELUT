\chapter{Application gallery}
\label{ch:apps}

Applications exist to keep pillars honest.
A compiler with no netlist is a speech; a melt with no cipher is a float
toy; a polymorphic cipher with no Red is a blog post.

Canonical nine-slot card: \corpus{directives/application-gallery.md}.

\section{Pillar~I (encrypted)}

\begin{enumerate}
  \item \textbf{Encrypted \texttt{full\_adder} SING.}
        Multi-LUT correctness at production-shaped $N$ (\cid{6}, \cid{20};
        \cid{21} is $e{=}0$ BK). Covering noisy adder is \cid{52}.
  \item \textbf{Encrypted tree / regex SING.}
        Compiler is not adder-specialized (\cid{6}, demo $N$).
  \item \textbf{Hardness $+$ noisy-BK certificates.}
        Estimator fill-in and covering-gadget residuals (\cid{5}, \cid{22},
        \cid{23}). Covering Track~A at $N{=}1024$, $\sigma{=}128$, $k{=}7$
        is \cid{52}--\cid{54}. Product-shaped \texttt{cryptoPublicMS} inject
        remains a graded failure (\cid{26}, \cid{56}); native $k{=}1$ remains
        \cid{37}/\cid{55} (\hid{4} remainder).
  \item \textbf{Encrypted sequential.}
        Counter (\cid{38}), toy \texttt{NOP}/\texttt{ADD} (\cid{40}),
        PicoRV32 \texttt{addi}+\texttt{sw}+\texttt{lw} at demo $N{=}8$
        (\cid{50}); Metal NOP-fetch (\cid{51}).
  \item \textbf{4-bit CSA vs ripple LUT cut} (\cid{42}).
        Architecture, not TensorLUT melt.
\end{enumerate}

\section{Pillar~I shape laboratory (oracle --- not FHE)}

\begin{enumerate}
  \item \textbf{Decision tree.}
        A 4-bit non-linear boundary, 7 LUTs. Exact threshold logic on a
        batch of records. Teaches: non-linear Boolean $\neq$ neural net,
        and $B$ is a capacity knob.
  \item \textbf{Regex / DFA search.}
        3-character matcher, 23 LUTs. Large $B$ turns unified memory into
        the story.
  \item \textbf{PicoRV32.}
        ${\sim}4.8\mathrm{k}$ LUTs, ${\sim}1.5\mathrm{k}$ DFFs. Scripted
        \texttt{resetn} boot. Oracle path: \cid{1}. Encrypted 1-tick at
        demo $N{=}8$: \cid{50} \texttt{lw} sees 1; Metal NOP-fetch \cid{51}.
\end{enumerate}
