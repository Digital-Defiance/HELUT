# Code of Conduct

This is a research repository. Disagreement about science is expected. Harassment is not.

- Critique claims, logs, and proofs. Do not attack people.
- Do not pressure anyone for a P1030680 plaintext, production keys, or “just make 176-bit mean secure.”
- The claim sheet and five-cell test are how we argue: [`CONTRIBUTING.md`](CONTRIBUTING.md).

Violations: contact Digital Defiance via [digitaldefiance.org](https://digitaldefiance.org) or the GitHub org admins.

This is not a substitute for GitHub’s [Acceptable Use](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies).
