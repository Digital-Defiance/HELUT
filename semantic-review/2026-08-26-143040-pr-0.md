# Fail-closed, source-pinned TensorLUT battery receipts

This follow-up closes most prior High/Medium blockers: runs now build current sources, reject `HELUT_BIN`, execute a copied hash-pinned binary, and cannot publish a passing incomplete summary. Parsing now derives baseline sanity, squeeze, verdict, return-code expectations, and most control outcomes; planted controls establish a live one-nonbinary defect, while null language stays limited to no-false-positive plumbing. Two receipt-integrity gaps remain: dirty/untracked inputs are not always reconstructible from the archived provenance, and planted exact recovery is still accepted as a self-reported Boolean rather than derived from a raw metric.

Watch for: **confirmed, Medium** the provenance archive omits untracked build/orchestration content; **confirmed, Medium** the runner trusts `planted_exact_recovery` inside its independently derived control result.

## High-level view

Execution is now source-built and run-local. Source inputs are inventoried around `swift build`, `.build/release/helut` is copied into the receipt directory, and its hash is checked before and after every completed arm; `HELUT_BIN` cannot bypass that chain.

Completion now fails closed. Interruptions and failures remain non-passing, and even a normally completed loop is downgraded unless its row count matches the matrix and every row records an accepted outcome.

The provenance bundle combines a Git base, a tracked-source patch, and a hash inventory. It reconstructs tracked dirty build inputs, but not untracked files or dirty orchestration scripts; the currently reviewed runner is itself untracked and is only represented by a hash.

Validation independently checks finite scores, lambda, contradiction count, squeeze, verdict, role-specific return codes, and the planted seed’s live one-nonbinary defect. Exact recovery is the remaining asymmetry: Swift emits only a Boolean, and Python uses that Boolean to derive the planted result.

Run-ID containment, historical full-budget defaults, explicit bounded selection, whole-LUT planted wording, and bounded evidence language all match the requested behavior.
